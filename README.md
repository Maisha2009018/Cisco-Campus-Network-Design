# Cisco-Campus-Network-Design
Simulation based segmented and secure campus network, designed using Cisco Packet Tracer
Main objectives of this Project are:

1. to make all switches and routers password protected. 

2. to design One of the departments would use the DHCP protocol to assign the IP addresses to all 
hosts of that network.  

3. to apply VLAN system, on one of the departments that would separate students and faculties 
networks.

5. to use a web server and a DNS server should be placed under the admin office. 

6. to apply any of our known dynamic routing protocols should be applied in the designed topology. 

7. to apply our desired ACL in routers to access the resources of the admin office. (For example, permit/deny any host/network to access the web server or any host in the admin office).
